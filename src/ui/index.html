    Music
    Using the music bot from your main account

    Discord only allows one voice connection per account. If repent runs on the account you're in voice with, it can't play to you. Run repent on an alt, add your main's user ID below, join a voice channel on your main and type !mplay. Whitelisted users can only use music commands.

    Music Whitelist
    These users can run music commands (mplay, mskip, mstop, mqueue, mnowplaying, mloop, mautoplay, mvolume) through this account. Nothing else.
    Default Volume
    Starting volume (0-200) when music starts in a server. Change it during playback with mvolume.
    Autoplay By Default
    Queue similar songs automatically when the queue runs out. Toggle per server with mautoplay.
